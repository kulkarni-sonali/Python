Why can’t we create (put) a list inside a set?”

Short answer

In Python, you cannot put a list inside a set because sets require their elements to be hashable (immutable), while lists are mutable (changeable). A set uses a hash table for fast lookups, and if an item's content changes, its hash value changes, breaking the set's structure. 
Sets require: Immutable/Hashable items (e.g., tuples, strings, numbers).
Lists are: Mutable/Unhashable (cannot be hashed).

merging, concatenation doesn't work in sets
